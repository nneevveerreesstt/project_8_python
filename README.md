# Проект Разработка A/B-тестирования нового алгоритма рекомендаций и анализ результатов
## Бизнес-контекст
Продукт - развлекательное приложение с функцией «бесконечной» ленты коротких видео. Монетизация построена на двух моделях: ежемесячная платная подписка, открывающая просмотр ленты без рекламы, и показ рекламы для пользователей, ещё не оформивших подписку. Команда разработчиков рекомендательных систем создала новый алгоритм, который, по их мнению, будет показывать более интересный контент для каждого пользователя. Чтобы проверить эту гипотезу, необходимо рассчитать параметры A/B-теста и проанализировать его результаты.
## Цель проекта
Проверить гипотезу о том, что новый алгоритм рекомендаций показывает более интересный контент для каждого пользователя, и оценить его влияние на ключевые продуктовые метрики с помощью A/B-теста.
## Задачи:
1. Рассчитать параметры теста.
2. Оценить корректность его проведения.
3. Проанализировать результаты эксперимента.
 
Основной инструмент - `Python`.
